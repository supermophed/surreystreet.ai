Surrey Street Partners ✦ June 29, 2026 ✦ 1 min read

This page is not real content. It's here to prove the build works: drop a markdown file into content/blog/, run the builder, and a fully-formed, SEO-ready post appears at /blog/<slug>/.

What this demonstrates

The builder renders the elements a real post will use:

  • Section headings (## and ###)
  • Bold and italic text
  • Links back to the canonical site
  • Inline code and lists

A sub-heading

Pull-quotes render with the brand accent rule, so a strong line from the post can be set apart.

When you're done eyeballing this, delete content/blog/sample-hello-world.md and re-run python3 build_blog.py — the post and its folder disappear from the listing, RSS, and sitemap.
